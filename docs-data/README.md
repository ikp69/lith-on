# Lith-On Website Markdown Content

This folder contains copy-ready Markdown content for the Lith-On
website, based on the supplied website content and FAQ documents.

## Files

-   `home.md` --- Homepage sections and calls to action
-   `about.md` --- Company overview, vision, mission and values
-   `solutions.md` --- Product and energy storage solution categories
-   `applications.md` --- Application areas and use cases
-   `capabilities.md` --- In-house engineering and integration
    capabilities
-   `why-lith-on.md` --- Differentiators and reasons to work with
    Lith-On
-   `faqs.md` --- FAQs grouped by topic
-   `sustainability.md` --- Sustainability content
-   `warranty-and-support.md` --- Warranty, installation and support
    copy

## Notes

-   Markdown headings are structured for direct use in a website CMS or
    content repository.
-   Product-specific warranty periods, certifications, performance
    figures, prices and other unprovided technical specifications have
    not been invented.
-   Replace generic contact calls to action with the website's actual
    contact route or form (`/contact`).
-   Visual implementation must adhere to the light-first architectural
    design specification in `design.md`: white/off-white canvas, Manrope
    typography, Lith-On Red (`#F74530`), and Lith-On Blue (`#0B3388`). Dark-blue
    default styling is prohibited.
